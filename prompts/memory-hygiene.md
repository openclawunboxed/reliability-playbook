# memory hygiene prompt

```text
review the current memory files for the following:
- stale facts
- duplicated instructions
- contradictory summaries
- oversized context that should be archived or removed

then:
1. keep only facts that still matter
2. move short-lived details to today.md
3. keep stable facts in stable-facts.md
4. remove or rewrite contradictory content
5. summarize the changes made and why
```
